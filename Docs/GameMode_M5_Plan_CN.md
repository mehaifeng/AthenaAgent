## 现状（读代码得出的底数）

## 二、人物关系（需求 1）

### 数（C#，`Services/GameMode/PolisRelations.cs`，纯函数）

- 关系值 −100…100，五档：亲近（≥ 60）、友好（25…59）、寻常（−24…24）、冷淡（−59…−25）、厌恶（≤ −60）。
- **起点按真实数据推**，不存：
  - 居民对你：那场会话办完了 +15、正在办 +5、做到一半停下 −10、定时差事 0；来回越多越熟（每回合 +1，最多 +15）；
    两周内动过 +5；性子（十二种脾气各有一个"暖度"，热心肠 +20 … 爱发牢骚 −15）。
  - 职业居民对你：按他们的人设各有一个起点（女祭司、图书管理员温和，铁匠、水手直爽，账房挑剔）。
  - 两人之间（有方向）：同一户 +40、住同一座楼（同一个文件夹）+25、标题相近（问话的分词，Jaccard）最多 +20、
    "缘分"（两人种子的哈希）−30…+30、年纪差一档 −5，再加上他自己的暖度。
- **事件改变它**（只有变化存盘：`AthenaData/Game/relations.json`，全局，原子写，读不懂就改名留着，不进任何城的存档——
  "居民从不存盘"这条照旧成立，存的是"发生过什么"）：
  - 你和他当面聊一句 +2（每人每小时最多 +6）；你在旁边说话、他接了一句 +1（每小时最多 +2）；
  - 敲门叫他出来、他出来了 +1；隔着门把他说烦了 −4；被打发或回绝之后 30 秒内又敲、或两分钟内敲三次 −3；
  - 两位居民闲聊了一次，彼此 +1（两人之间因闲聊累计最多 +15）。
  - 变化随时间淡去：半衰期 30 天。删掉的会话，它的记录在下次存盘时清掉。
- **由它推出的行为参数**也在 C# 算、随关系一起推给页面：隔着门的耐心（1–5 轮，按关系与脾气：慢性子、沉稳多一轮，急性子、爱发牢骚少一轮）、
  叫他出来答不答应（寻常及以上答应）、隔着门说到头是出门来谈还是请你走（友好及以上出门）。

### 推给页面（`relations`）

`{ you: { id: { score, band, patience, opens, comesOut, why: [原因键…] } }, pairs: [[a, b, ab, ba]…], ties: { id: { friends, rivals } } }`：
`you` 覆盖这座城所有居民（街上、屋里）与十位职业居民；`pairs` 只给街上的人与职业居民（行为要用）；`ties` 每人最多三个朋友、三个不和的人（总览要用）。
没有任何消息正文，只有 Id、名字、数和原因键（"那件事办完了""聊过几次""被你敲烦了"……由页面本地化）。城的人变了、或者发生了事件，推一次（按指纹去重）。

### 进对话（提示词）

- 和他聊（`BuildChat`）、他接你的话、几个人接你的话：多一句"你对城的主人的态度"（按档的一句描述）。
- 两位居民闲聊（`BuildAmbientLine`）：多一句"你和他的交情"（按档）。
- 隔着门说话：见第五节。

### 进行为（页面）

- 打招呼按档：亲近的转身挥手、说得热络；友好的挥手；寻常的点头说一句；冷淡的只看你一眼不说话；厌恶的转过身去。
  招呼的话仍是本地的（`Polis.Citizen.Greet` 按档分成几组）。
- 闲聊挑人：合得来的优先凑一对（距离相同时按两人的关系排），互相厌恶的两位不凑一对。
- 辩论的围观者里，喜欢你的先为你挥手（挥手的人数照旧按票数）。
- 门、你说话时的反应：见第三、五节。

### 关系总览（入口）

左上角工具条加"人际"按钮（`btn-relations`，夜里同色）。点开一张 DOM 面板（与卷轴阅读器同一套：文字一律 `textContent`，
挡着时方向键不走路，Esc 收起）：左边是城里每个人对你的态度（半身像、名字、档位、一根 −100…100 的条，按分数排），
点一个人，右边是他为什么这样看你（原因）和他的朋友、不和的人。职业居民排在一起。

## 三、几个人一起接话（需求 6）

- 你在对话栏里自己说一句（不点名）：6 米内、在画面里的人都会有反应，最多 6 位：
  亲近——转身、挥手；友好——转身、点头；寻常——转过来听；冷淡——只转头瞥一眼；厌恶——转过身去。
  正在和别人闲聊的、陪审团里的、和你当面聊着的不算。
- 开口的最多三位（`pickResponders`，纯函数：越近、越喜欢你、越健谈的越先；厌恶你的不开口），一个接一个：
  新意图 `chorus { text, who: [按顺序] }`；C# 依次让每一位说一句，后说的听得到前面几位说了什么，提示词里有他对你的态度
  和他对前面说话那位的交情。第一位走 Player 池，后面的走新的 Chorus 池（每小时 60 次，同一时刻只一句）。
  说完推 `chorus-end`；你又开口了，上一轮没轮到的不再说。
- 没配模型：谁也不开口，动作照旧有。

## 四、门（需求 2）

- **有门的建筑**：民居（户的民居一样；两户并排的那种两扇门）、作坊、货栈——门槛不高于 0.3 米、门前 1.6 米内找得到能站的地方、
  从那里走得到街上。其余的（柱廊书库、雕塑园、金库、粮仓、罐棚、废墟）没有会开的门，住在那里的人照旧在门口待着。
- **门扇**：一块带木纹的单扇木门挂在门洞前，合页在左边，向屋里开 92°（开着时扇板转进墙里，看得到的是门洞里的暗处；夜里是灯光）；
  关着时四边留一道缝，夜里透出光来。开门 0.35 秒、关门 0.35 秒。
- **门前的路**（`doors.mjs`，纯函数）：门前按法线往外找第一个能站的点（门阶），再在 0.2 米的格子上 A* 找到街上的站点、拉直，
  整条路每 0.25 米都能站（和居民的路同一条规矩）。找不到的门就当没有门。
- **居民的日子加上"在屋里"**：周期仍是 150 秒——屋里 15 秒 → 开门出来（1.6 秒）→ 门前 30 秒 → 走去一处 → 待 25 秒 → 走回来 →
  门前 → 进门（1.6 秒）→ 屋里 15 秒。屋里的人不画、不摆、不分档、不闲聊、不打招呼；门开不开由此刻有没有人在门里进出决定，
  所以同一刻永远是同一个样子。
- 你进不去：门板是墙上的一块，占用栅格不变（断言照旧）。

## 五、敲门（需求 3）

- 有人住的门，门阶前按 E："敲门"。你转向门、抬手敲两下，门上冒出"咚、咚"。
- **屋里有谁**：此刻在屋里的街上居民，加上街上满了没上街的那些（他们一直在屋里；C# 的 `citizens` 多推一份 `indoors`，只有 Id、名字、家、种子）。
  - 没人：门上一句"（没有人应门）"。
  - 有人：门上冒出"谁呀？"，底部面板列出屋里的人（名字、对你的态度）。选一位（只有一位就直接是他），他隔着门答一句（本地的话，按关系），
    面板换成三个按钮：**请他出来**、**隔着门说话**、**算了**。
- **请他出来**：关系不低于寻常——"好，我这就出来"，门开，他走到门阶上面朝你，他的卡片打开（可以接着聊）；
  低于寻常——在门里回绝一句。街上满了的那些人出来时临时上街（同时最多 2 位访客），你走开或聊完 20 秒后回屋。
- **隔着门说话**：对话栏借给他（"隔着门对……说"），他的话出现在门上的气泡里。C# 记轮数（新的一次敲门重新数）：
  到了他的耐心那一轮，友好及以上的说一句"我出来跟你说吧"然后出门（门开、他走出来、栏接着借给他，话回到他头顶）；
  其余的不耐烦地请你走（栏还回去，关系 −4，三分钟里再敲他不应）。最后一轮怎么收由 C# 定、写进提示词，模型只负责把它说出来；
  页面按 C# 推来的结局（`talk` 里的 `door`）演。
- 敲得太勤（被回绝或打发之后 30 秒内、或两分钟内三次）：门里一句"别敲了！"，关系 −3。
- 门上的气泡和头顶的气泡一样按当帧矩阵投影，进运动自检。

  在公共地方干活的，去处就定在那里（走得到的话）。门前那两段时间是干活，在去处待着的那 25 秒也是（在那儿干的话）。

连同大小一起按人的身高缩放。
