# 游戏模式 M1 手动验收清单

> 2026-10-11。M1 把城邦接进了应用：中间区域可以在对话与游戏之间切换。设计见 `Docs/GameMode_Design_CN.md`，
> 进度、决定与证据见 `Docs/GameMode_Progress_CN.md`。自动化测试已覆盖的部分（存档、差异、意图校验、四处失败……）
> 这里不再重复；这份清单只列需要人在真实窗口里看一眼、点一下的事。每一项后面的「预期」是通过的样子。

## 0. 准备

- 构建并启动应用（开发机）：`dotnet build Athena.UI.sln -p:UseAppHost=false`，然后照常运行。
- 准备一个**测试用的工作区文件夹**（不要用重要的文件夹：第 4 节会在应用外增删其中的文件夹），里面放三四个子文件夹，
  各放几份文档、图片、表格。在左侧「添加工作区」把它加进来，并在里面开一个会话。
- 建议右侧日志面板开着：游戏模式的 Warning（失败、被拒绝的网页意图）都会出现在那里。

## 1. 进入游戏

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 在对话标题栏右端点神殿图标（右栏折叠按钮左边） | 中间那一行变成城邦；输入框还在下面；宠物收起来了；标题栏的「上下文」和猫头鹰按钮不见了 |
| 1.2 | 第一次进入这个工作区 | 先出现一座城（几秒内），每个顶层文件夹一座建筑，名牌是文件夹名；镜头从高处推近一次（奠基揭幕，只播这一次） |
| 1.3 | 在输入框里发一条要动文件的消息（例如「把某个文件夹里的文档列个清单写进 清单.md」） | 雅典娜（白衣、周身有光）走到对应的建筑，头上冒旁白（「我去书库翻翻《…》」）；写文件时搭脚手架；等模型时原地沉思、光一明一暗 |
| 1.4 | 让她做一件需要审批的事（例如执行一条终端命令，审批模式为「平衡」） | 原生审批窗口照常弹出；城里她停在门槛前，旁白「这一步需要你点头」；**网页里没有任何「批准」按钮** |
| 1.5 | 等这一回合结束 | 她把一件**红色**的东西放在你脚下（报告是卷轴、表格是账册、图片是彩绘板，只回答不写文件时是一卷回答），脚下一圈白环一胀一缩；走出画面时屏幕边缘有红色三角指着它 |
| 1.6 | 点那件东西 | 底部出现卡片：「读 / 打开 / 收下 / 退回」 |
| 1.7 | 点「读」 | 回答类：城邦里打开卷轴阅读器，Markdown 排好版，里面的 HTML 只是文字；文件类：在右侧工作台打开（Office 文件走预览） |
| 1.8 | 点「收下」 | 颜色褪掉、沉进城里；重启后它仍是「已收下」 |
| 1.9 | 另一件点「退回」 | 输入框里预填「关于《…》，请修改：」并聚焦，**不会自动发送**；你写完按发送，才在同一会话里追加这条修改要求 |
| 1.10 | 点「回到对话模式」（同一位置的按钮） | 幕布一闪，气泡树重建，回到原来的对话；宠物回来 |
| 1.11 | 切回游戏、最小化窗口一会儿再还原 | 还原后画面接着动（不可见时页面停止渲染，见日志里没有报错） |

## 2. 切换工作区（会话树是唯一的选择来源）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 游戏模式下，在左侧点**同一个工作区**里的另一个会话 | 不换场景、不航海；雅典娜转向那份委托，出现在它最后一次动作的地点（没有工具调用就站在广场） |
| 2.2 | 点**另一个工作区**里的会话 | 航海过场（海、船、「驶向『…』」），靠岸后是那座城；切换会话**不会**把你踢回对话模式 |
| 2.3 | 点「全局对话」里的会话 | 驶向「雅典娜的神殿」：一座只有公共建筑的城，神庙更大；在那里的文件操作都算「城外」（她出城门） |
| 2.4 | 用方向键在会话树里一路按过去 | 列表跟手，游戏这边没有卡顿；停下来那一次才换城 |
| 2.5 | 第一次去一个大文件夹 | 过场至少约 1.6 秒；完整测绘慢于约 6 秒时先靠岸，只有顶层建筑，其余随后出现 |

## 3. 重启后恢复

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 停在游戏模式时退出应用，再启动 | 直接进入游戏模式（模式存在设置里） |
| 3.2 | 回到刚才那座城 | 城立刻按上次的快照画出来，随后在后台核对；没处理的成果仍然是红的；你的位置回到上次走到的地方 |
| 3.3 | 退出前让一个回合正在进行，然后退出 | 重启后那份委托的建筑上是停工的脚手架，旁白「上次在这里停下了，要接着做吗？」 |
| 3.4 | （第 4 节的离线部分会再覆盖「离开期间的报告」） | — |

**注意**：启动时选中的仍是「最近更新的会话」，不是「上次选中的会话」——设计稿 15.5 留给你决定，M1 没有改这一点。

## 4. 在应用外增删文件夹

开着应用、停在这座城里：

| # | 操作（在访达 / 资源管理器里） | 预期 |
|---|---|---|
| 4.1 | 新建一个文件夹，放一两个文件 | 一两秒内城市边缘起一座新建筑；**没有**光、没有雅典娜的动作；右上角「广场公告板」多一条「『…』在应用外被新建了」；其他建筑一座都不挪 |
| 4.2 | 删除一个文件夹 | 那座建筑拆掉，留一圈地基石（空地）；公告板记一条 |
| 4.3 | 给一个文件夹改名 | 建筑原地换牌匾（地块不变） |
| 4.4 | 往某个文件夹里一次拷进几百个文件（或在仓库里 `git checkout` 另一个分支） | 公告板「城里起了大变化，正在重新测绘」，随后整城一次到位 |
| 4.5 | 让雅典娜写一个文件（第 1.3 步那种） | 那座建筑也会更新，但公告板**不**记这一条（是她做的） |

关掉应用、或者切到别的城邦之后：

| # | 操作 | 预期 |
|---|---|---|
| 4.6 | 改名一个文件夹、删除另一个、移动一件已交付的文件到别的文件夹 | 回来时传令官播报「你离开期间」：改名（原地换牌匾）、删除（留下空地）、成果换了地方（已找回）；点「知道了」收起 |
| 4.7 | 把一件已交付的文件彻底删掉 | 报告里写「…找不到了」；那件成果只剩空底座，记录还在，**不会自动删除** |
| 4.8 | 把整个工作区文件夹移到别处，再回到这座城 | 城笼罩在雾里，卡片「找不到这座城邦的文件夹」+「重新定位」 |
| 4.9 | 点「重新定位」，选移动后的文件夹（或者在左侧工作区菜单里选「重新定位文件夹…」） | 雾散开，城还是原来的布局；存档、成果、工作区知识都在（只改了目录，Id 没变） |

## 5. 失败提示（设计稿 12.5 的四处）

在一台一切正常的电脑上，用环境变量让游戏模式在某一处"失败"一次（只用于验收；设置后启动时日志里有一条 Warning 提醒它开着）：

| # | 启动方式 | 预期 |
|---|---|---|
| 5.1 | `ATHENA_POLIS_FAILURE=create` | 进入游戏模式时，游戏区显示「游戏模式没能打开」：原因「这台电脑上没能创建内嵌浏览器（WebView）」、可复制的技术细节、「重试」「回到对话」；日志一条 Warning（`Game mode failed at Create`） |
| 5.2 | `ATHENA_POLIS_FAILURE=navigation` | 同上，原因「游戏页面没能加载」 |
| 5.3 | `ATHENA_POLIS_FAILURE=webgl` | 同上，原因「这里的网页环境不支持 WebGL 2，城邦画不出来」 |
| 5.4 | `ATHENA_POLIS_FAILURE=timeout` | 约 20 秒后同上，原因「游戏页面迟迟没有就绪」 |
| 5.5 | 任一种失败后点「回到对话」 | 回到对话模式（是你点的，不是悄悄退回）；再点神殿图标会重试一次 |
| 5.6 | （有条件时）在一台没装 WebKitGTK 的 Linux 上进入游戏模式 | 与 5.1 相同的面板与 Warning——Linux 走同一条路，不静默降级 |

去掉环境变量重新启动，一切恢复正常。
