# 游戏模式第四轮：游戏内核对清单

对应 `Docs/GameMode_M6_Plan_CN.md` 的九件事。每条写的是怎么做、应该看到什么。不对的在行首打 ✗，在后面写一句你看到的情况。
旧的游戏存档不用管：关系账本里按会话记的旧条目会在第一次存盘时清掉。

准备：在设置里给「虚拟宠物与居民」（Companion）配一个模型；不配的话会借用标题生成角色。

## 1–2 居民从建筑来

- [ ] 进一个只有一两个会话、但有好几个文件夹的工作区：街上有人在走，不再空荡荡。
- [ ] 进一个文件夹很少（不到 4 个）的工作区：城郊多出几座民居（村舍），名牌是「某某一家」，里面住着人。
- [ ] 进神殿岛（选一个不属于任何工作区的会话）：有 6 座村舍，街上有人。
- [ ] 退出游戏再进同一座城：街上还是那几个人，名字和长相都一样。
- [ ] 新建或删除一个会话：城里的人不变（人跟着建筑走，不跟会话走）。
- [ ] 走近一个人按 E，卡片上写着：职业 · 年纪 · 性子、住在哪（楼名，或者「市集的摊位」「某某一家」）、全城人口一行（「住着 N 位，白天街上有 M 位」）。卡片上不再有「看看那场会话」。
- [ ] 打开「人际」：人数比街上多，屋里的人标着「在屋里」。
- [ ] 街上的人不会超过 32 个（大城市里看一看，大致数一下）。
- [ ] 敲一扇门，请屋里一位不在街上的人出来：他出来的同时，画面外有一位街上的人回了家。他回屋以后，那位又会出来。

## 3 名字、个性、职业、上下文

- [ ] 和一个人「聊几句」，问他住的那座楼里有什么：他能说出楼里的几个文件或子目录，或者说出 README 里写的事。
- [ ] 问他这个项目是做什么的：他能大概说出来（根目录 README 里的内容，或者几座楼的名字）。
- [ ] 和他闲扯天气、吃饭：他也接得住，不硬往项目上扯。
- [ ] 问他现在几点、在干什么：答得和实际对得上（比如在田里锄地、在市集吆喝、在家门口）。
- [ ] 两个人自己闲聊时，说的是日常，不念文件内容。

## 4 日出晚归（夜晚跟着应用主题）

- [ ] 白天切到深色主题：天黑下来，街上的人**不会一下子消失**，而是陆续回家进门；五分钟内街上只剩零星几个人（最多 4 个，十位职业居民照常在岗）。
- [ ] 夜里打开游戏（应用本来就是深色）：一进城街上就只有零星几个人。
- [ ] 天亮（切回浅色主题）：人一个一个出门，不会一齐涌上街。
- [ ] 夜里和还在外面的人聊几句：他说话的样子是夜里的（时间晚了、语气安静些）。

## 5 职业与新资产

- [ ] 城北城墙外有一排田（麦子、菜、葡萄架）和一个用木栅栏围起来的牧场，羊在里面慢慢走动，不会走出栅栏。
- [ ] 走进田里，能在垄沟之间走；牧场的栅栏挡路，朝城那一侧有个口。
- [ ] 北门前的路没有被田挡住。
- [ ] 农夫在田里锄地；牧人拄着牧杖站在牧场里、靠近栅栏口的地方，看着羊；织工在家门前的立式织机前织布，手在经线上；商贩在市集上招手吆喝。
- [ ] 渔夫在栈桥边钓鱼，陶工、面包师、石匠、木匠、鞋匠、乐师照旧干活。
- [ ] 有的人什么活都不干，只是闲逛（无业的人）；卡片上写「无业的人」。

## 6 辩论

- [ ] 在讲台提一个议题开始辩论：围观的人站得比以前近（离辩台两三米）。
- [ ] 辩论的近景里滚动滚轮或按住中键拖：能拉远拉近，镜头不会再被拉回去；辩论结束后视角恢复。

## 7 默认视角

- [ ] 刚进游戏，右下角的视角是「跟着你」，走动时镜头跟着你。
- [ ] 还能切到「自由」和「跟着雅典娜」。

## 8 雅典娜和人说话

- [ ] 站在广场附近等一两分钟：雅典娜会走到某个人跟前，两人面对面聊起来，她头顶有气泡。
- [ ] 打开「人际」，点一个人：能看到他怎么看雅典娜（敬重的、不服的都有）。
- [ ] 不服她的人和她说话时语气冷淡一些，但不会出口伤人。

## 9 细节

- [ ] 雕塑园和港口的雕像：带刻字的台座，人像有斜挂的外袍和长矛。
- [ ] 港口的船：有船舷、船眼、撞角、收起来顺着船身搁着的桨、卷起来的帆和绑帆的绳、船尾的舵桨。
- [ ] 港口有麻袋、晾网架；陶工作坊的窑后有一垛柴；木箱有木板和箍，篮子是编的、里面有果子。

## 顺带看一眼

- [ ] 一直开着游戏玩十几分钟：不卡、不白屏。
- [ ] 进出游戏、换城、切主题，没有报错面板。
