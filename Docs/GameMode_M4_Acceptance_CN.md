# 游戏模式手动验收（M4：居民、问话、辩论、户与民居）

> 2026-10-13 改向之后的里程碑（`Docs/GameMode_Progress_CN.md` 顶上的几节）在真机上的验收清单。每个里程碑完成时追加它那一节；
> 自动化测试管得到的（夹具城、无头、冒烟、运动自检）不在这里重复，这里只列只有人在真窗口里看得出的。
> 开发版：`dotnet run`，会话头部的游戏模式按钮进城。神殿岛（没有工作区的全局对话）与一个有文件夹的工作区各看一遍。

## M-B 居民生成器

- [ ] **街上有人。** 有十几场以上会话的城里，街上走着、站着的人不超过 32 位；城里会话少于 32 场时，每场会话都有一位在街上。
- [ ] **人住在他干过活的地方。** 一场改过某个文件夹里文件的会话，它的居民在那座楼门前一带走动；全局对话（神殿岛）的居民都住广场一圈、市集、图书馆、神庙、港口。
- [ ] **走路不穿墙、不卡人。** 盯一位走动的居民一程：不穿过房子、讲台、祭坛；几个人碰到一起会让开；你迎面走过去，他侧身让你，不挡你的路。
- [ ] **一城之内不撞脸。** 广场上同时看到的人里，衣色、发式、胡子、头带、身高的组合没有完全一样的两位；同一场会话下次进城还是同一个人。
- [ ] **E 开他的卡片。** 走到一位居民跟前，脚下出现"E 和……说话"，按 E：镜头推近到你们两个之间，他站定、转身、挥手；卡片上是他的半身像、
      两三句话（那件事办到哪一步、常去哪个文件夹或来回谈了几次、过去多少天）和一行人口；"去看那份委托"选中那场会话（会话树上同一行高亮）。
- [ ] **台词里没有正文。** 翻几位的卡片：只出现文件夹名、数字和天数，没有任何一句是从对话里摘出来的。
- [ ] **闲聊与打招呼。** 在广场待一会儿：偶尔有两位站着的居民面对面说两句（头顶两个气泡轮流），全城同时只有一组；你走到一位闲着的人跟前，他会转身挥手说一句。
- [ ] **老居民的碑。** 一场一年多没动过的会话：他不在街上，他家门前有一块小碑；走到碑前按 E，卡片列出刻在上面的名字。
- [ ] **删掉一场会话，他就不在了。** 在会话树上删一场会话，切回游戏：几秒内他从街上消失，人口少一位。
- [ ] **帧率。** 街上满 32 位时转镜头、走路不明显卡顿（夹具城测得 Chromium 34–37 fps、WebKit 约 26 fps，见 Progress 的 M-B 一节）。
