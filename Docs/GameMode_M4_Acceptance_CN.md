# 游戏模式手动验收（M4：居民、问话与聊天、辩论、户与民居）

> 2026-10-13 改向之后的里程碑（`Docs/GameMode_Progress_CN.md` 顶上的几节）在真机上的验收清单。每个里程碑完成时追加它那一节；
> 自动化测试管得到的（夹具城、无头、冒烟、运动自检）不在这里重复，这里只列只有人在真窗口里看得出的。
> 开发版：`dotnet run`，会话头部的游戏模式按钮进城。神殿岛（没有工作区的全局对话）与一个有文件夹的工作区各看一遍。

## M-B 居民生成器

- [ ] **街上有人。** 有十几场以上会话的城里，街上走着、站着的人不超过 32 位；城里会话少于 32 场时，每场会话都有一位在街上。
- [ ] **人住在他干过活的地方。** 一场改过某个文件夹里文件的会话，它的居民在那座楼门前一带走动；全局对话（神殿岛）的居民都住广场一圈、市集、图书馆、神庙、港口。
- [ ] **走路不穿墙、不卡人。** 盯一位走动的居民一程：不穿过房子、讲台、祭坛；几个人碰到一起会让开；你迎面走过去，他侧身让你，不挡你的路。
- [ ] **一城之内不撞脸。** 广场上同时看到的人里，衣色、发式、胡子、头带、身高的组合没有完全一样的两位；同一场会话下次进城还是同一个人。
- [ ] **E 开他的卡片。** 走到一位居民跟前，脚下出现"E 和……说话"，按 E：镜头推近到你们两个之间，他站定、转身、挥手；卡片上是他的半身像、
      那场会话的信息（委托的标题、办到哪一步与完成了几回合、多久前动过、常去的文件夹）和一行人口；"去看那份委托"选中那场会话（会话树上同一行高亮）。
- [ ] **名字是完整的希腊名。** 翻几位的卡片：名字是一个完整的希腊名（不带会话标题），男女的名字不一样；同一座城里没有重名；切换界面语言，同一个人还是同一个名字（中文、英文各一份）。
- [ ] **看看那场会话。** 卡片上点「看看那场会话」：卷轴阅读器里是那场会话，只有「你」和「雅典娜」说的话，没有工具调用、工具结果、推理；很长的会话开头写着更早的几条没有列出。
- [ ] **卡片上没有摘出来的话。** 卡片本身只出现标题、文件夹名、数字和天数，没有任何一句是从对话里摘出来的（那场会话的原话只在你点开的阅读器里）。
- [ ] **闲聊（只用模型）。** 配好「虚拟宠物与城里的居民」的模型，在广场待一会儿：偶尔有两位站着的居民面对面停下来——先开口的那位头顶一串循环的点，然后他的话一个字一个字地出来；说完另一位头顶一串点，再接一句；两句说的是城里的事、天气、各自的营生，每次都不一样。全城同时只有一组；他们说话时站着不走，说完接着过日子。
- [ ] **没配模型就没有闲聊。** 把两个角色都清空：居民之间不再说话（没有任何预置台词），也不弹任何提示；打招呼照旧。
- [ ] **打招呼。** 你走到一位闲着的人跟前，他会转身挥手说一句（本地的话）。
- [ ] **老居民的碑。** 一场一年多没动过的会话：他不在街上，他家门前有一块小碑；走到碑前按 E，卡片列出刻在上面的名字。
- [ ] **删掉一场会话，他就不在了。** 在会话树上删一场会话，切回游戏：几秒内他从街上消失，人口少一位。
- [ ] **帧率。** 街上满 32 位时转镜头、走路不明显卡顿（夹具城测得 Chromium 34–37 fps、WebKit 约 26 fps，见 Progress 的 M-B 一节）。

## M-C 问话 → 聊天（2026-10-13 改：他的话出现在他头顶）

先在设置的模型角色里给「虚拟宠物与城里的居民」（或「标题生成」）选一个模型。

- [ ] **聊几句。** 走到一位居民跟前按 E，卡片上有「聊几句」；点它，卡片收起，底部的对话栏换成他的半身像和名字，占位字是「对……说……」，光标已经在栏里。
- [ ] **话在头顶。** 说一句「今天风大吗？」回车：你的话出现在你头顶；他头顶先是一串循环的点，然后他的回答一个字一个字地出来（不是在卡片或对话栏里）；说完之后对话栏回到可以写的样子，可以接着说。
- [ ] **他有自己的性子。** 和两三位居民各聊几句闲话（天气、城里的事、他的营生）：他们说话的口气不一样，会提到自己的行当，知道这座城叫什么、雅典娜住在城里；问他托付过的那件事，他只凭那场会话里的话答，没有的就说记不清。
- [ ] **他记得刚才说过什么。** 接着上一句追问（"那押金呢？"）：他接得上。
- [ ] **推理模型不露思考。** 换一个会先思考的模型：思考那几秒他头顶一直是点，不冒出一段推理。
- [ ] **Esc 告辞。** 聊天时按 Esc（或点回城里去走动）：栏还给雅典娜，你之前写给她的半句话还在；他最近那一句在头顶留一会儿再淡掉，他接着过他的日子（不会飞快地滑走）。
- [ ] **雅典娜不过来。** 聊天时雅典娜不会被叫过来、也不停下；镜头停在你和他之间。
- [ ] **不进会话。** 聊完回到对话模式：那场会话里没有多出任何消息，输入框里也没有你说的话。
- [ ] **没配模型。** 把两个角色都清空再说一句：他头顶是"先在设置里……选一个模型"，没有错误框。
- [ ] **限流。** 第一位还没答完时转身和第二位说话：第二位头顶是"还在想上一个问题"一类的话。

## M-E 辩论

- [ ] **讲台前按 E。** 广场上传令官站的讲台：走到台阶前，脚下出现"E 上讲台辩论"（旁边有居民也是它）；按 E 是讲台的卡片——一段说明、你的战绩、「提一个议题」。
- [ ] **提议题。** 点「提一个议题」：底部的对话栏换成辩论（左边是雅典娜，占位字"提一个议题……"）；写一句、回车。雅典娜走到讲台前的一侧（远了化作一道光过来），站定面对你；顶上出现辩论牌（议题、第 1 / 3 轮）。
- [ ] **三轮。** 每轮你写论点、回车：栏上写着"雅典娜在想她的反驳……"；她答了，头顶一个气泡（第一句），整段在顶上的辩论牌里；然后轮到你下一轮。她的话针对你刚才那句、不超过两三句、用议题的语言。
- [ ] **陪审团。** 第三轮她说完：栏还给雅典娜（你之前写给她的半句话还在）；附近的居民走过来，在讲台前站成半圆、面朝舞台；几秒后辩论牌上是裁决（谁赢、几票对几票、一句理由），为你投票的那几位隔一会儿挥一次手。
- [ ] **战绩。** 再到讲台按 E：卡片上的战绩多了这一场。换一座城、重启应用，战绩还在（它是全局的）。
- [ ] **随时不辩。** 辩到一半按 Esc（或点辩论牌上的「结束」、或走远）：辩论牌消失，居民慢慢走回去，这一场不记战绩。
- [ ] **说不出来也往下走。** 断网或把主对话模型改成一个不存在的名字再辩：她那一轮是"（雅典娜想了想，这一轮让给你。）"，辩论照常走完；陪审团也说不出来时算平局。
- [ ] **限流。** 一小时里第十一场：讲台说"这一个钟头辩得够多了"，不开辩。

## M-D 户与民居

- [ ] **神殿有了房子。** 进神殿岛：全局对话的居民住进了几座民居（不再站在广场一圈、神庙门口）；每座民居的名牌是「……一家」（立户那一位的希腊名）。
- [ ] **同一类事住一户。** 几场标题相像的会话（都在说合同、都在写周报）住在同一户；标题都是「新会话」的按开始的月份分户；一户最多 6 人。
- [ ] **有文件夹的照旧。** 工作区的城里，碰过某个文件夹的会话，居民照旧住在那座楼门前；只有没碰过文件夹的进户。
- [ ] **民居不挪位。** 离开再回来、重启应用：每座民居还在原来那块地上；新建、删除文件夹，民居不动，新文件夹也不占民居的地。
- [ ] **新立一户。** 在城里时新开一场会话、聊一句（标题与已有的户都不像、又是新的一个月的话）：几秒内一座新民居出现，名牌闪一下，雅典娜说「……在城里安了家」，那一位从新民居门前出门。
- [ ] **户散了。** 删掉一户里所有的会话：那座民居拆掉，留下一圈地基石（空地）。
- [ ] **人多的城。** 一座有几十场没碰过文件夹的会话的城：最多 16 座民居，再多的人仍住广场一圈。
