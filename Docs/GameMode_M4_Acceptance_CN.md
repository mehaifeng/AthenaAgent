# 游戏模式手动验收（M4：居民、问话、辩论、户与民居）

> 2026-10-13 改向之后的里程碑（`Docs/GameMode_Progress_CN.md` 顶上的几节）在真机上的验收清单。每个里程碑完成时追加它那一节；
> 自动化测试管得到的（夹具城、无头、冒烟、运动自检）不在这里重复，这里只列只有人在真窗口里看得出的。
> 开发版：`dotnet run`，会话头部的游戏模式按钮进城。神殿岛（没有工作区的全局对话）与一个有文件夹的工作区各看一遍。

## M-B 居民生成器

- [ ] **街上有人。** 有十几场以上会话的城里，街上走着、站着的人不超过 32 位；城里会话少于 32 场时，每场会话都有一位在街上。
- [ ] **人住在他干过活的地方。** 一场改过某个文件夹里文件的会话，它的居民在那座楼门前一带走动；全局对话（神殿岛）的居民都住广场一圈、市集、图书馆、神庙、港口。
- [ ] **走路不穿墙、不卡人。** 盯一位走动的居民一程：不穿过房子、讲台、祭坛；几个人碰到一起会让开；你迎面走过去，他侧身让你，不挡你的路。
- [ ] **一城之内不撞脸。** 广场上同时看到的人里，衣色、发式、胡子、头带、身高的组合没有完全一样的两位；同一场会话下次进城还是同一个人。
- [ ] **E 开他的卡片。** 走到一位居民跟前，脚下出现"E 和……说话"，按 E：镜头推近到你们两个之间，他站定、转身、挥手；卡片上是他的半身像、
      两三句话（那件事办到哪一步、常去哪个文件夹或来回谈了几次、过去多少天）和一行人口；"去看那份委托"选中那场会话（会话树上同一行高亮）。
- [ ] **台词里没有正文。** 翻几位的卡片：只出现文件夹名、数字和天数，没有任何一句是从对话里摘出来的。
- [ ] **闲聊与打招呼。** 在广场待一会儿：偶尔有两位站着的居民面对面说两句（头顶两个气泡轮流），全城同时只有一组；你走到一位闲着的人跟前，他会转身挥手说一句。
- [ ] **老居民的碑。** 一场一年多没动过的会话：他不在街上，他家门前有一块小碑；走到碑前按 E，卡片列出刻在上面的名字。
- [ ] **删掉一场会话，他就不在了。** 在会话树上删一场会话，切回游戏：几秒内他从街上消失，人口少一位。
- [ ] **帧率。** 街上满 32 位时转镜头、走路不明显卡顿（夹具城测得 Chromium 34–37 fps、WebKit 约 26 fps，见 Progress 的 M-B 一节）。

## M-C 问话

先在设置的模型角色里给「虚拟宠物与城里的居民」（或「标题生成」）选一个模型。

- [ ] **问他那件事。** 走到一位居民跟前按 E，卡片上有「问他那件事」；点它，卡片收起，底部的对话栏换成他的半身像和名字，占位字是「问……那件事……」，光标已经在栏里。
- [ ] **雅典娜不过来。** 问话时雅典娜不会被叫过来、也不停下；镜头停在你和他之间。
- [ ] **他只记得自己那件事。** 找一场你记得细节的会话，问它里面的一件事（比如合同的期限）：一到三句、用你提问的语言答；问一件那场会话里没有的事，他说不记得，不编。
- [ ] **等他答。** 回车之后栏上写着「……在想……」、输入框停用；几秒内卡片重新打开在这一问一答上，太长的有「读全文」，阅读器里是同样的字。
- [ ] **不进会话。** 问完回到对话模式：那场会话里没有多出任何消息，输入框里也没有你的问题；你之前写给雅典娜的半句话还在对话栏里。
- [ ] **Esc 不问了。** 写问题时按 Esc：栏还给雅典娜；等他答时按 Esc 也一样，回答到了只记在他的卡片上（十分钟内再走过去按 E 还看得到）。
- [ ] **没配模型。** 把两个角色都清空再问：他说一句"先在设置里……选一个模型"，没有错误框。
- [ ] **限流。** 连着问两个人（第一个还没答完就问第二个）：第二个说"还在想上一个问题"。

## M-E 辩论

- [ ] **讲台前按 E。** 广场上传令官站的讲台：走到台阶前，脚下出现"E 上讲台辩论"（旁边有居民也是它）；按 E 是讲台的卡片——一段说明、你的战绩、「提一个议题」。
- [ ] **提议题。** 点「提一个议题」：底部的对话栏换成辩论（左边是雅典娜，占位字"提一个议题……"）；写一句、回车。雅典娜走到讲台前的一侧（远了化作一道光过来），站定面对你；顶上出现辩论牌（议题、第 1 / 3 轮）。
- [ ] **三轮。** 每轮你写论点、回车：栏上写着"雅典娜在想她的反驳……"；她答了，头顶一个气泡（第一句），整段在顶上的辩论牌里；然后轮到你下一轮。她的话针对你刚才那句、不超过两三句、用议题的语言。
- [ ] **陪审团。** 第三轮她说完：栏还给雅典娜（你之前写给她的半句话还在）；附近的居民走过来，在讲台前站成半圆、面朝舞台；几秒后辩论牌上是裁决（谁赢、几票对几票、一句理由），为你投票的那几位隔一会儿挥一次手。
- [ ] **战绩。** 再到讲台按 E：卡片上的战绩多了这一场。换一座城、重启应用，战绩还在（它是全局的）。
- [ ] **随时不辩。** 辩到一半按 Esc（或点辩论牌上的「结束」、或走远）：辩论牌消失，居民慢慢走回去，这一场不记战绩。
- [ ] **说不出来也往下走。** 断网或把主对话模型改成一个不存在的名字再辩：她那一轮是"（雅典娜想了想，这一轮让给你。）"，辩论照常走完；陪审团也说不出来时算平局。
- [ ] **限流。** 一小时里第十一场：讲台说"这一个钟头辩得够多了"，不开辩。
