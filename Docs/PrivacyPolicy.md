# AthenaAgent 隐私政策

最后更新日期：2026 年 6 月 28 日

AthenaAgent（以下简称"本应用"）由开发者 haifeng（GitHub: mehaifeng）维护。本隐私政策说明本应用如何处理您的信息。

## 一、我们（开发者）不收集任何信息

本应用**不内置任何遥测、崩溃上报或使用分析**。
开发者不运营任何接收本应用用户数据的服务器，不收集、不存储、不转发您的聊天内容、知识库、文件、API Key 或其他个人信息。

## 二、本应用对外通信的真实情况

本应用是本地运行的桌面工具，仅在您**主动使用某项功能**时，才与下列第三方服务通信，且通信内容**由您在设置页填写的 API Key / Endpoint 决定目的地**。这些通信**不经过开发者控制的任何服务器**。

| 触发条件 | 目的地 | 传输内容 |
|---|---|---|
| 发起对话、使用工具调用、生成图像、生成语音、生成向量 | 您在设置中配置的 AI 服务商（OpenAI 兼容协议，例如 OpenAI、Anthropic 兼容代理、DeepSeek、智谱、月之暗面、MiniMax、自部署等任意兼容端点） | 您的消息文本、知识库检索片段、对话历史、您主动上传的附件 |
| 启用"网络搜索"工具 | 您选择的搜索服务商（Tavily / 智谱 / 百度智能云） | 您的搜索关键词 |
| 启用"文档解析"功能 | mineru.net（极速解析模式）或您填入 Token 的精度解析端点 | 您提交的待解析文档 |
| 应用启动时自动检查更新 | api.github.com（mehaifeng/AthenaAgent 仓库的 Release API） | 仅当前应用版本号 |
| 您手动启用浏览器自动化时 | 由 Playwright 驱动的本地 Chromium | 您的浏览指令 |

> 上述所有通信的目的地由**您**在设置中选择，开发者不参与转发、不留存副本，也无法访问这些数据。请同时参阅各第三方服务商的隐私政策。

## 三、本地数据

以下数据仅保存在**您自己的设备**上，应用目录 `AthenaData/` 下：

- 应用配置（含您填入的 API Key、Endpoint、知识库路径等）
- 对话历史
- 知识库 Markdown 文件与向量索引（SQLite）
- 运行日志（Serilog）

卸载应用或删除 `AthenaData/` 目录即可彻底清除上述数据。开发者无法远程访问这些数据。

## 四、未成年人

本应用不针对 13 岁以下儿童设计。如您未满 18 岁，请在监护人陪同下使用。

## 五、政策变更

本政策如有重大变更，会随应用版本更新发布在仓库（github.com/mehaifeng/AthenaAgent）的 Release Notes 中。继续使用本应用即视为接受变更后的政策。

## 六、联系我们

如有疑问、要求删除数据或投诉，请通过 GitHub 仓库的 Issue 联系我们：
https://github.com/mehaifeng/AthenaAgent/issues

## 简明摘要

- 开发者**不**收集您的任何数据。
- 您的数据**只在您主动触发时**，按您自选的目的地直连第三方（AI / 搜索 / 文档解析），不经开发者服务器中转。
- 所有数据默认保存在您本机的 `AthenaData/`。
- 应用启动时只向 GitHub 检查更新，传输内容仅为版本号。
