# AthenaAgent 隐私政策

最后更新日期：2026 年 11 月 16 日

AthenaAgent（以下简称"本应用"）由开发者 haifeng（GitHub: mehaifeng）维护。本隐私政策说明本应用如何处理您的信息。

## 一、我们（开发者）不收集任何信息

本应用**不内置任何遥测、崩溃上报或使用分析**。
开发者不运营任何接收本应用用户数据的服务器，不收集、不存储、不转发您的聊天内容、知识库、文件、API Key 或其他个人信息。

## 二、本应用对外通信的真实情况

本应用在您的设备上运行。您使用相关功能、已启用的后台任务触发或游戏中的居民自动交谈时，应用会与下表中的服务通信。AI、搜索和文档解析使用相应的设置，检查更新连接 GitHub。应用直接请求这些服务。

| 触发条件 | 目的地 | 传输内容 |
|---|---|---|
| 发起对话、使用工具调用、生成图像、生成语音、生成向量 | 您在设置中配置的 AI 服务商（OpenAI 兼容协议，例如 OpenAI、Anthropic 兼容代理、DeepSeek、智谱、月之暗面、MiniMax、自部署等任意兼容端点） | 您的消息文本、知识库检索片段、对话历史、您主动上传的附件 |
| 定时消息触发或后台知识库整理运行 | 主对话、知识库整理和向量化所配置的 AI 服务商 | 定时消息使用该任务的提示词及其调用所需的对话和工具上下文。知识库整理使用重复候选和整理工具读取的知识库内容，向量化使用待索引的知识库分块 |
| 游戏模式里主动与居民交谈，或对话栏里的发言由附近第一位居民接话 | "虚拟宠物与城里的居民"角色的服务商（未配置时使用"标题生成"角色） | 本句及与该居民近期最多 6 轮游戏内闲聊、城市概况（含最多 12 个顶层文件夹名）、居民人设、关系与当时的活动。普通居民还会收到住所对应的文件夹概况及项目简介，其中可能包含文件名和 README 片段 |
| 游戏模式里附近其他居民接话（每小时最多 60 次调用） | 同上 | 您本次的发言、前几位的接话、城市概况、接话者的人设、活动与关系 |
| 游戏模式里居民或雅典娜自动闲聊（每小时最多 60 次调用） | 同上 | 城市概况、闲聊双方的人设、活动与关系，以及该次闲聊里对方刚说的一句 |
| 游戏模式里在广场讲台前和雅典娜辩论（您提议题、写下每一轮的论点） | 您给"主对话"角色配置的 AI 服务商（雅典娜的发言）；"虚拟宠物与城里的居民"角色的服务商（没配就用"标题生成"角色的，陪审团判票） | 议题与这场辩论的全部发言；不含任何对话记录 |
| 辩论时每一轮雅典娜说完（围观的居民起哄，每轮一次） | "虚拟宠物与城里的居民"角色的服务商（没配就用"标题生成"角色的） | 议题、这一轮您与雅典娜的两段发言，以及这座城的名字、建筑对应的顶层文件夹名（最多 12 个）、居民人数、白天还是夜里；不含任何对话记录 |
| 启用"网络搜索"工具 | 您选择的搜索服务商（Tavily / 智谱 / 百度智能云） | 您的搜索关键词 |
| 启用"文档解析"功能 | mineru.net（极速解析模式）或您填入 Token 的精度解析端点 | 您提交的待解析文档 |
| 在关于页面检查更新 | GitHub 的 AthenaAgent Release API 及发行版资源 | 请求最新发行版元数据及所需的更新清单。应用在本地比较版本 |
| 您手动启用浏览器自动化时 | 由 Playwright 驱动的本地 Chromium | 您的浏览指令 |

> 开发者不参与转发、不留存副本。第三方服务对请求数据的处理方式见各服务商的隐私政策。

## 三、本地数据

以下应用数据保存在您设备上的 `AthenaData/` 目录：

- 应用配置（含您填入的 API Key、Endpoint、知识库路径等）
- 对话历史
- 知识库 Markdown 文件与向量索引（SQLite）
- 运行日志（Serilog）

如需移除这些本地应用数据，可退出应用后删除 `AthenaData/` 目录。

## 四、未成年人

本应用不针对 13 岁以下儿童设计。如您未满 18 岁，请在监护人陪同下使用。

## 五、政策变更

本政策如有重大变更，会随应用版本更新发布在仓库（github.com/mehaifeng/AthenaAgent）的 Release Notes 中。继续使用本应用即视为接受变更后的政策。

## 六、联系我们

如有疑问、要求删除数据或投诉，请通过 GitHub 仓库的 Issue 联系我们：
https://github.com/mehaifeng/AthenaAgent/issues
