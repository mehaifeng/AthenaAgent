# 虚拟宠物 · 互动指南

改造前的宠物只能被拖来拖去：它是一个会动的状态指示灯，点它没有任何事情发生。

这一版把它变成一个**有反馈闭环的伙伴**——你能对它做事，它也会主动向你提出请求；
相处会积累成可以查看的档案；它说的话可以由一个独立的小模型来写。

拖动、抛掷、空闲漫游全部保留，行为不变。

---

## 一、五种操作

| 操作 | 结果 |
|------|------|
| **左键单击** | 摸摸头。如果它头顶正挂着需求（见第三节），这一下**直接回应那个需求**——提示符就是这次点击的含义 |
| **左键拖动** | 移动 / 抛掷（不变） |
| **右键** | 打开互动菜单：摸摸头 / 喂点心 / 陪它玩 / 说句话 / 宠物档案 / 让它休息 / 隐藏宠物 |
| **把文件拖到它身上** | 它把文件叼进当前会话的待发送附件区，等同于拖到输入框 |
| **鼠标悬停** | 显示状态提示（名字 · 等级 · 称号，或当前正在做的事） |

没有双击操作——双击和单击会互相抢反馈，单击的摸头必须是即时的。
所有次级操作都在右键菜单里，菜单本身支持键盘上下键与回车。

### 关于「陪它玩」
它会真的跑起来：一次明显的横向冲刺，开启重力时还会跳一下。
**即使你关掉了「允许空闲漫游」，陪玩仍然会动**——关闭漫游的意思是"别自己乱跑"，
不是"我叫你你也别动"。

### 关于「说句话」
只有在开启模型台词、并且模型角色可用时才可点击（见第四节）。
不可用时它是灰的，而不是点了没反应。

## 二、成长：三个数值，一条曲线

宠物有三个数值。每一个都有明确的来源和去处，没有靠挂机自己涨的东西。

### 心情 Mood（0–100）
| 事件 | 变化 |
|------|------|
| 摸摸头 | +6 |
| 喂点心 | +12 |
| 陪它玩 | +10 |
| 回应了它的需求 | 额外 +6 |
| 一轮对话成功结束 | +2 |
| 一次工具调用失败 | −5 |
| 需求挂了 12 分钟没人理 | −4（每次需求只扣一次） |
| 随时间 | 以每小时 9 点的速度回到基线 55 |

### 精力 Energy（0–100）
| 事件 | 变化 |
|------|------|
| 喂点心 | +25 |
| 陪它玩 | −8 |
| 空闲 / 休息时 | 每小时 +14 |
| Athena 正在思考、调工具或宠物正在移动时 | 每小时 −7 |

### 经验 Exp 与等级
| 事件 | 经验 |
|------|------|
| 摸摸头 | +2 |
| 喂点心 | +5 |
| 陪它玩 | +6 |
| 回应了它的需求 | 额外 +8 |
| 一轮对话成功结束 | +3 |
| **每天第一次互动** | +15 |

升到 N 级需要累计 `25 × N × (N−1) ÷ 2` 点经验：
2 级 25 点、3 级 75 点、5 级 250 点、10 级 1125 点，上限 20 级。

等级对应称号：初识（1–3）、伙伴（4–7）、老友（8–11）、挚友（12–16）、形影不离（17–20）。

### 冷却：只挡收益，不挡反馈
| 互动 | 冷却 |
|------|------|
| 摸摸头 | 45 秒 |
| 陪它玩 | 5 分钟 |
| 喂点心 | 15 分钟 |

冷却期内**照样有动画和台词**，只是不再加数值，台词也会换成"等我一下下"这类。
按钮不会变灰——变灰会让人以为点坏了，而无限刷数值会让养成失去意义。

### 存档
- 位置：`AthenaData/pet_profile.json`
- **按宠物分别记账**：换一只宠物是认识一位新伙伴，上一只的等级原样保留，换回来还在
- 心情和精力是**按时间戳惰性推算**的：关掉应用八小时再打开，它确实休息好了，
  而不是像时间没走过一样
- 文件损坏时会被隔离为 `.corrupt` 并从空档重来，不影响应用启动

## 三、需求：它会主动找你

这是这次改造的核心——交互不再是单向的。

| 需求 | 触发条件 | 头顶提示符 | 用什么回应 |
|------|----------|-----------|-----------|
| 饿了 | 精力 ≤ 30 | ♨ | 喂点心 |
| 无聊 | 心情 ≤ 40 | ♪ | 陪它玩 |
| 想被理一理 | 45 分钟没有任何互动 | ♡ | 摸摸头 |

优先级：饿 > 无聊 > 寂寞（越具体的诉求越优先）。

规则：

1. 需求出现时，它会说一句话，之后就只靠头顶的提示符，**不会反复打扰你**。
2. **用错的互动不会清掉需求**——它饿的时候你摸它，摸头照常生效，但它还是饿。
   头顶那个符号就是"该做什么"的说明。
3. 回应对了：额外 +8 经验、+6 心情，并进入 20 分钟静默期，它不会连着要东西。
4. 挂了 12 分钟还没人理：扣 4 点心情，**只扣一次**。
5. 条件不再成立时（比如你因为别的原因喂了它），需求自动消解。

Athena 正在思考或调用工具时，头顶显示的是工具符号而不是需求符号——
那时候你要看的是模型在干什么。

## 四、台词：本地台词库 + 可选的模型台词

宠物说话有两级来源。

### 本地台词库（默认，零成本）
内置中英文台词，按场景（摸头 / 投喂 / 陪玩 / 升级 / 各种需求 / 接住文件 / 回答完成 / 闲聊）
和心情档位（低落 / 普通 / 高兴）分类。离线可用，零延迟，不产生任何请求。

### 模型台词（可选，默认关闭）
`设置 → 通用 → 用模型生成宠物台词`

开启后，气泡会**先显示本地台词，模型那句到了再替换**。
所以模型慢了、超时了、限流了、没配置——你只会看到本地台词，不会看到任何失败。

**用哪个模型**：`设置 → 模型 → 虚拟宠物` 角色。
没配置时自动借用**标题生成**角色（同样是"一句话、低延迟、便宜"的场景），
两个都没配就整体不可用，命令变灰。

**发出去的是什么**（这决定了你要不要开）：
- 宠物自己的状态：场景、名字、等级、心情、精力、当前需求
- 最近一次工具名
- **当前对话中你最近一次输入的前 80 个字符**（作为话题线索）

不发送对话历史、不发送模型回复、不发送附件内容。关闭开关即完全不发送。

**限流**（宠物是装饰件，不允许它在后台悄悄产生持续开销）：
- 两次模型台词最短间隔 45 秒
- 每小时最多 20 次
- 同时只允许 1 个请求在途
- 8 秒硬超时
- 输出截断到 40 字符，并剥掉引号、加粗与多余的行

## 五、宠物档案

右键 → `宠物档案`（再次点击或点击面板外部关闭）。

面板里有：等级与经验进度条、心情、精力、相处天数、互动次数、回应过的需求数、
摸头次数、见证过的对话数与工具调用数，以及三个快捷按钮（摸摸头 / 喂点心 / 陪它玩）。

「见证过的对话 / 工具调用」是宠物视角的使用统计——它在旁边看着 Athena 干了多少活。

---

## 六、设置项一览

`设置 → 通用 → 虚拟宠物`

| 开关 | 默认 | 说明 |
|------|------|------|
| 显示虚拟宠物 | 关 | 总开关 |
| 宠物大小 | 50% | 25%–100% |
| 允许空闲漫游 | 开 | 只影响**自发**移动，不影响陪玩和拖动 |
| 漫游区域 | 消息区下半部 | 也可选日志/终端区底部、会话列表区底部 |
| 重力与抛掷 | 开 | 拖动松手后的下落与回弹 |
| 减少宠物动画 | 关 | 停掉逐帧动画与互动动画；需求也不再主动弹气泡 |
| **启用宠物互动** | 开 | 关掉后退回纯状态指示器：不能摸/喂/玩，不显示需求与气泡，档案面板关闭。拖动和漫游不受影响 |
| **用模型生成宠物台词** | 关 | 见第四节 |

「隐藏宠物」菜单项等同于关掉总开关，会写回配置。

---

## 七、关掉之后会怎样

- **关掉「启用宠物互动」**：宠物还在，还会动、还会反映 Athena 的工作状态，
  但不再有摸头、需求、气泡和档案。已有的成长记录原样保留，重新打开就能接上。
- **关掉「显示虚拟宠物」**：宠物消失。存档不会被删除。
- **删除 `AthenaData/pet_profile.json`**：所有宠物的成长记录清零，从初识重新开始。
