# 游戏模式 M3 手动验收清单

> 2026-10-11。M3 按用户定下的六条（见 `Docs/GameMode_Progress_CN.md` 的 M3 一节）做了三件事：按形态的碰撞（不再是地块大的方盒子）、
> 一套更顺的程序化动画（跑、说话、挥手、接过、停着时的小动作、动作之间的过渡、看向对方、弹簧骨上的衣摆与面纱）、
> 更细的人物（有五官的头、有手指的手、有脚趾和凉鞋的脚、灰度写实的皮肤与织物材质）与重画的灰度素描半身像，外加对话时推近的近景。
> 自动化已覆盖的部分（足迹的规则、整座城的可达性、姿势的周期与边界、弹簧骨的定长与确定性、过渡、看向、清单的新动作名……）这里不再重复；
> 这份清单只列需要人在真实窗口里看一眼、走一走的事。M1、M2 的清单仍然有效。
>
> **2026-10-13 起雅典娜不镜像回合（直播拿掉了，见 `Docs/GameMode_Progress_CN.md` 顶上一节）。** 2.5 的「她停着时旁白气泡在说」只剩奠基时的两句；
> 2.7 改为「成果出现在你脚下时你伸手接一下」；4.9 只剩她手里的家什作为美术资产可在图鉴里看（城里她不再写字、读卷轴、收缆、等审批、交付）；
> 5.2 的「雅典娜召唤侍女时平举双臂」废止（飞出去的侍女已经拿掉）。2026-10-13 起黄金侍女这位居民也拿掉了，2.8、5.4 里关于她的那几项不再验收。

## 0. 准备

- 构建并启动应用（开发机）：`dotnet build Athena.UI.sln -p:UseAppHost=false`，然后照常运行；打开一个有十来个文件夹的工作区，切到游戏模式。
- 页面侧的自动化先过一遍：`node --test Tools/GameMode/web/test/*.test.mjs`、冒烟 `smoke.mjs`、运动自检 `motion.mjs`（命令见 `CLAUDE.md`）。

## 1. 碰撞（决定 1：0.4 米以上的东西挡路）

| # | 做什么 | 预期 |
|---|---|---|
| 1.1 | 按住 W 走向一座民居，到了墙边继续按 | 停在墙外；斜着按方向键沿墙滑到街口，不卡死 |
| 1.2 | 走进一座有院墙的民居的院子（院门开在正面） | 院门能进，院子里能走，房门是贴在墙上的板，进不了屋 |
| 1.3 | 走到一棵橄榄树下 | 树干挡住你，树冠底下绕得过去；柏树挡的是它整个底部 |
| 1.4 | 在广场上撞委托板、长凳、讲台、日晷、方柱头像 | 每一样各挡自己那一块，之间都能走 |
| 1.5 | 走进市集 | 摊位的柜台挡路，摊位之间能走（M2 时整块市集封着） |
| 1.6 | 走过北边的城门 | 门洞能过、门柱挡 |
| 1.7 | 走到港前石台，沿东侧步道走到场馆门前的过道 | 底座挡路、过道能站；石台边的矮石沿迈得过去，海里走不进去 |
| 1.8 | 走向一只酒杯、油灯或地上待收的卷轴 | 不挡（矮于 0.4 米的东西不挡路；成果要走过去点，永远不挡） |
| 1.9 | 设立神谕之后走向神庙前的三足鼎与月桂 | 挡路；撤了神谕又能走过 |

## 2. 动画（决定 2：A 档）

| # | 做什么 | 预期 |
|---|---|---|
| 2.1 | 按住 Shift + 方向键 | 换成跑的步态（大步、前倾、肘弯着摆），速度明显快；松开 Shift 回到走 |
| 2.2 | 走、停、再走 | 停和走之间有约 0.2 秒的过渡，不是一帧跳过去；下摆走起来滞后一点、停下来回摆一下 |
| 2.3 | 站着不动看自己一两分钟 | 隔十来秒来一个小动作（看一眼、换重心、抱臂、挠头、整衣），不是每次都一样 |
| 2.4 | 走到雅典娜身边站住 | 她看着你（头转过来），你也看着她；走开到 7 米外头回正 |
| 2.5 | 点雅典娜或按 Enter 打开对话栏 | 你转身面向她、站着听；托付之后两秒多你比划着"说"；她停着时旁白气泡在说，她就在比划 |
| 2.6 | 点一位居民 | 他转过来先挥一下手，然后一边比划一边讲 |
| 2.7 | 她把成果递到你脚下 | 你伸手接一下 |
| 2.8 | 看女祭司、传令官、黄金侍女走路 | 面纱、斗篷、辫子跟着晃；起风时衣摆往北飘（风从海上来） |
| 2.9 | 换一座城（海图里选一座岛） | 衣摆不会从上一座城甩过来（瞬移时重新安放） |

## 3. 美术（决定 3、4、5）

| # | 做什么 | 预期 |
|---|---|---|
| 3.1 | 滚轮推到最近（6.5 倍） | 人约 300 像素高；脸上有眼睛、眉毛、鼻子、嘴唇、耳朵，手有手指，脚有脚趾和凉鞋 |
| 3.2 | 对话栏开着 | 镜头自己推到你和她中间的近景、俯角放低；收起之后退回原来的远近 |
| 3.3 | 居民的卡片开着 | 同样推近到你和他中间 |
| 3.4 | 看对话栏与居民卡片上的半身像 | 灰度素描：皮肤有明暗、眼睛有虹膜和高光、嘴唇两片、头发有发丝、衣褶有阴影；三种神情分得出 |
| 3.5 | 对着铁匠、图书管理员的近景 | 胡子有一缕缕的起伏，不是光滑的一枚蛋；老人的脸有法令纹和眼袋 |
| 3.6 | 近景里看衣料 | 读得出是织物（织纹的法线），不是塑料壳；皮肤有毛孔一级的粗糙度变化 |
| 3.7 | 点缀色 | 仍然只在"轮到你了"的东西上（待收的成果、等审批的封印）；半身像里没有一点红 |

## 4. 第三轮：裙摆、走近按 E、告示与卷轴、过场、工具、夜里

自动化已覆盖的（腿的覆盖率、接触点、按键、夜里的消息、长卷能滚到底）不再重复；这里只列要在真实窗口里看一眼的。

| # | 做什么 | 预期 |
|---|---|---|
| 4.1 | 按住 Shift + W 从站着直接冲出去，跑一段再急转 | 裙摆一直裹着腿：前襟搭在前腿外面、后摆甩在身后，任何一帧都看不到整条腿露在裙摆外 |
| 4.2 | 走到雅典娜跟前 | 她脚下出现"E 和雅典娜说话"；按 E 对话栏展开并聚焦，打字时 E 是字、人不动；用鼠标点她不再有反应 |
| 4.3 | 依次走到一位居民、地上待收的成果、委托板、神庙前、一座场馆前、一棵橄榄树前 | 各自脚下出现对应的提示（和他说话 / 看看「…」/ 看看委托板 / 看看每日神谕 / 进…看看 / 去「…」这份委托），按 E 打开；再按 E 收起卡片或面板 |
| 4.4 | 收下一件成果后点"摆放"，走到一个空底座前 | 提示变成"摆在这里"，按 E 摆上去 |
| 4.5 | 打开委托板 | 每条建议都在正文那一栏里左对齐，长的折成两行，按钮在那一行右边；没有字压到半身像上或伸出面板 |
| 4.6 | 让雅典娜写一份很长、带表格的回答，收下后"读" | 卷轴整卷都在窗口里，滚轮或 PageDown 能滚到最后一行；表格有表头、按冒号对齐，嵌套列表、任务列表、删除线、代码、引用都对 |
| 4.7 | 在海图上选另一座岛（换工作区） | 城往后退一点、渐隐进过场：天、云、两座岛、海、一条会起伏的希腊船，标题牌上的小船沿航线走；靠岸时新城从略远处推近 |
| 4.8 | 走进锻炉 | 铁匠隔着铁砧面朝外，抡起锤、锤头落在砧面的铁条上，左手的火钳按着铁条；工匠对着那块石料，左手的凿子抵着石面、右手的木槌敲在凿尾上；你站在地坪上，脚不陷进去 |
| 4.9 | 看雅典娜写字、读卷轴、收缆、等审批、交付 | 蜡板平托在左掌上、笔尖落在板上；两只手各攥一根卷轴的轴；缆绳从船上拉过来穿过两只拳头、垂到脚边一盘；石板两手捧在胸前、红封印朝外；成果横在两只掌心上递出来 |
| 4.10 | 看画师、账房、女祭司、图书管理员干活 | 画师对着画架、笔尖碰到画面；算板平放在左掌上、右手拨石子；祭碗托在两只掌心上；卷轴攥在拳里举上格子 |
| 4.11 | 在应用里切换深色 / 浅色主题（游戏模式开着） | 城里一秒多走到夜里（月光、天色压暗、只有雅典娜亮着），对话栏、视角、阅读器、面板一起换色；切回来一样；关掉游戏再打开，直接就是当前主题，不先白一下 |

## 5. 第四轮：工匠的右臂、袖子、讲台

自动化已覆盖的（右肘右拳在身体哪一边、手臂进没进躯干、袖子裹着上臂、居民一圈路线上脚下与身体里的东西）不再重复；这里只列要在真实窗口里看一眼的。

| # | 做什么 | 预期 |
|---|---|---|
| 5.1 | 走进锻炉，从工匠的右边和身后各看几下敲击 | 左手的凿子抵着石面、凿尾斜着朝向他的右手；右肘贴在身体右侧，木槌在身体右前方抬起、往左下劈到凿尾上——右臂不横过胸口 |
| 5.2 | 看铁匠举锤、抄写员挥手、雅典娜召唤侍女时平举双臂、测绘员手搭额前 | 袖子跟着上臂一起抬起来，肩头没有留下一块不动的布、没有方垫肩；举过头时从袖口看进去是布，不是一圈纸 |
| 5.3 | 在广场看传令官（戴宽檐帽、拿权杖）一会儿 | 他站在日晷旁讲台的台面上，脚不陷进石头；一直在台上，不从台子侧面走下去、走回来 |
| 5.4 | 去神殿（全局对话）看神庙前的侍女 | 她站在神庙台阶前的地上，不陷在台基里 |
