# 游戏模式 M0 演示说明

> 2026-10-11。M0 是一个在普通浏览器里跑的原型，不接入应用、不调用任何模型：一座由文件夹生成的城邦，加一段按真实节奏回放的会话。设计见 `Docs/GameMode_Design_CN.md`，进度与证据见 `Docs/GameMode_Progress_CN.md`。
> M1 之后页面挪进了应用（`Assets/Polis/`，应用里由回环服务的 `/polis/` 路由提供）；这份回放演示照样可用，下面的地址已按新位置改过。应用里的游戏模式怎么验收，见 `Docs/GameMode_M1_Acceptance_CN.md`。

M0 的通过标准（设计稿第 14 节）：**给两三个不懂技术的人看，不做任何解释，他们能说出雅典娜在干什么。** 这份说明就是为这件事准备的。

## 1. 启动回放

需要：一个浏览器（Chrome / Edge / Safari 都行，要有 WebGL 2）和一个本地静态服务。仓库里的东西都是离线的（three.js 已经打包在 `Assets/Polis/vendor/`），不需要装任何东西、不联网。

在仓库根目录起服务（它按应用里的样子挂载：`/polis/` 是页面，`/fixtures/` 是合成夹具，`/.local/` 是被忽略的真实夹具）：

```bash
node Tools/GameMode/web/test/serve.mjs 8766
```

没有自己的 Node 时，构建过应用的机器上有一份：`bin/Debug/net10.0/.playwright/node/<平台>/node`。

然后在浏览器打开：

| 回放 | 地址 | 时长（1 倍速） |
|---|---|---|
| 合成城邦（默认，推荐给不懂技术的人看） | `http://127.0.0.1:8766/polis/index.html` | 约 1 分 30 秒 |
| 真实会话（本仓库 + 一段真实会话，需先导出，见第 3 节） | `http://127.0.0.1:8766/polis/index.html?fixture=../.local/real-fixture.json&speed=2` | 约 5 分 30 秒，2 倍速约 2 分 45 秒 |

操作：

- 右下角按钮：暂停 / 继续、速度（×1 / ×2 / ×4）、镜头（跟着雅典娜 / 跟着你）、重新开始。
- 键盘：空格暂停，`1` `2` `4` 调速度，`F` 切换镜头，`R` 重新开始，`H` 隐藏左上角的状态行。
- 鼠标：左键点地面，你（深色斗篷的人）就走过去；点红色的卷轴会弹出一张卡片，点"收下"颜色就褪进城邦；右键拖动平移镜头，滚轮缩放。
- 地址参数：`&t=30000` 从第 30 秒开始，`&paused=1` 先暂停，`&speed=2` 2 倍速。

## 2. 画面里有什么

- **城邦就是文件夹**：每座建筑是一个顶层文件夹，名牌上是文件夹名。主要放文档的是柱廊书库（一排柱子的长廊），放代码的是作坊（屋前有木棚、旁边有窑），放图片的是雕塑园，放表格的是金库（门口两根柱子的小神殿），放压缩包的是仓库，什么都有的是民居。很久没动的爬常春藤，一年没动的是废墟。
- **公共建筑是能力**：广场中央立着委托板；神庙在北；圆形的图书馆是"记忆"；锻炉是"终端命令"；港口是"上网"；城门外是"工作区以外的地方"。
- **雅典娜**：穿白色长裙、周身有光的女子。光只属于她：她在哪干活，哪里就亮；在等模型时她原地沉思，光一明一暗。
- **你**：深色斗篷的人，开始时站在广场上。
- **颜色只有一个意思："轮到你了"**。全城是黑白灰的，唯一有颜色的是她交给你的赤陶红卷轴（脚下有一圈白环一胀一缩）；它跑出画面时，屏幕边缘会出现一个带"!"的红色三角指着它。

## 3. 导出真实会话的夹具（只在开发机上做）

真实夹具含有工作区里真实的文件夹名和文件名（没有任何消息正文、命令或参数），只写进被 `.gitignore` 忽略的 `Tools/GameMode/.local/`。

```bash
dotnet build Tools/GameMode/PolisExport/PolisExport.csproj -p:UseAppHost=false
```

```bash
dotnet Tools/GameMode/PolisExport/bin/Debug/net10.0/PolisExport.dll list --db bin/Debug/net10.0/AthenaData/conversations.db --workspace-id <工作区 Id>
```

`list` 只列会话 id 前缀、回合数、工具调用数和日期，不列标题。挑一个"有总时长的气泡"等于回合数的会话（时间是实测的，不是估的），然后：

```bash
dotnet Tools/GameMode/PolisExport/bin/Debug/net10.0/PolisExport.dll fixture --root . --db bin/Debug/net10.0/AthenaData/conversations.db --conversation <会话前缀> --out Tools/GameMode/.local/real-fixture.json --ledger Tools/GameMode/.local/real-ledger.json
```

`--ledger` 把布局账本存下来：下次再导出，已有的建筑原地不动，新文件夹在城市边缘占新地。

## 4. 给不懂技术的人看时注意什么

**不要解释。** 通过标准就是"不做任何解释也能说出她在干什么"。开场只说一句"看一会儿，然后告诉我你觉得她在做什么"，别说"AI""智能体""工具调用""文件夹映射成建筑"这类词，也别先讲颜色的含义——看他们自己能不能发现红色卷轴是给自己的。

**先用合成城邦。** 合成城邦的文件夹叫"合同""照片""账本""网站""下载"，和普通人的电脑相近；真实夹具是本仓库（`Services`、`ViewModels`、`Docs` 这样的代码目录），不懂技术的人读不出名牌的意思，适合作为第二轮或给技术同事看。

**1 倍速看第一遍。** 等模型的沉思是真实节奏（中位约 5 秒）。如果观众明显走神，再切 2 倍速；不要一开始就快进，否则他们看不清她走到了哪里。

**在第 2 节表里的时刻暂停提问**（空格暂停），每个时刻记一行：

| 时刻 | 观众原话 | 说对了 / 部分 / 没说对 |
|---|---|---|
| 去书库读合同 | | |
| 递红色卷轴 | | |
| 锻炉 | | |
| 港口放船 | | |
| 化作光过去 | | |
| 侍女 | | |
| 城外失败 | | |

**让他们自己动手一次**：请他们点一下红色卷轴（收下），再点一下地面让"你"走过去。记下他们是否自己发现这两件事。

**别替他们圆**：观众说错了也不要纠正，只记下来。说错的地方正是 M1 要改的地方。

**环境**：用 1600×1000 以上的窗口（小窗口里名牌会挤在一起）；页面只有中文；没有声音。打不开时页面会直接说明原因（需要 WebGL 2、读不到夹具），不会静默变成白屏。

**隐私**：真实夹具和 `Tools/GameMode/.local/` 里的截图含真实的文件夹名、文件名，只给有权看到这些名字的人看，不要外发。

## 5. 已知的局限（给观察者看，不必告诉观众）

- 雅典娜"干活时更亮"在默认镜头距离下偏弱：照亮范围有限，读的时候主要靠她身上的光和气泡（M2 美术再加强）。
- 人物在游戏视距下只有几十像素高，手里的卷轴、石板、锤子看不清；动作主要靠地点、船、侍女、脚手架和旁白来读。
- 一个代码仓库里大半是作坊，建筑之间的差别来自体量和细节，远看仍然相近；名牌是主要的区分。
- 回合之间的空闲被剪成 3 秒，所以下一回合可能在她刚递完东西时就开始。
