# Markdown 渲染回归样例

用于 Athena.UI 的 `LiveMarkdown.Avalonia` 手工视觉回归。建议分别在浅色、深色主题下粘贴或预览本文，并在流式输出尚未结束时观察控件是否稳定。

## Emoji

短码：:smile: :rocket: :thumbsup: :owl: :fire:

直接输入：😄 🚀 👍 🦉 🔥 🛠️ ✅ ❌

## 文本修饰

粗体、*斜体*、***粗斜体***、~~删除线~~、==高亮==。

H~2~O 是水，2^10^ = 1024。

## 嵌套引用

> 外层引用：浅色主题下文字应始终清晰。
>
> > 第二层引用：背景只应轻微加深。
> >
> > > 第三层引用：黑色文字仍须保持足够对比度。
