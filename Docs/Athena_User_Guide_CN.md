# Athena 使用文档（中文）

## 1. 产品概述
Athena 是基于 .NET 与 Avalonia UI 的桌面 AI 助手，集成了对话、工具调用、浏览器自动化、任务调度和本地知识库管理能力。

## 2. 环境要求
- Windows / Linux / macOS（桌面环境）
- .NET 10 SDK
- 可用的模型 API 凭据（按你使用的服务商配置）

## 3. 快速开始
1. 克隆项目：
```bash
git clone https://github.com/mehaifeng/AthenaAgent.git
cd AthenaAgent
```
2. 还原依赖：
```bash
dotnet restore
```
3. 启动应用：
```bash
dotnet run
```

## 4. 首次配置
1. 打开 `Config` 标签页。
2. 设置模型服务商、接口地址与 API Key。
3. 配置默认模型映射，以及可选的浏览器/搜索设置。
4. 保存配置，必要时重启应用。

## 5. 主要标签页与用法
### Chat
- 主对话区，用于提交任务目标和接收智能体响应。
- 支持工具驱动任务，例如文件操作和命令执行。

### Tasks
- 创建定时或周期任务。
- 用于提醒、延迟执行和例行检查。

### Browser
- 执行浏览器任务（navigate、click、type、wait、extract）。
- 多标签页场景下，建议先切换并确认当前活动标签页，再重复打开动作。

### Knowledge Base
- 导入并管理本地 Markdown 知识文件。
- 支持语义检索，增强对话上下文质量。

### Logs
- 支持按时间范围、级别、关键字过滤日志。
- 可从界面导出当前过滤结果。

### About
- 查看版本与项目信息。
- `OpenGitHub` 会打开官方仓库：
  `https://github.com/mehaifeng/AthenaAgent`

## 6. 推荐工作流
1. 先完成模型凭据配置。
2. 在 `Chat` 给出明确目标。
3. 需要网页操作时，触发浏览器任务，并在证据/日志中确认执行结果。
4. 将可复用材料沉淀到 `Knowledge Base`。
5. 出现异常时到 `Logs` 检查并导出诊断信息。

## 7. 常见问题排查
- API 调用失败：检查 endpoint、密钥和网络连通性。
- 浏览器任务循环：核对最新标签页状态与日志，确认页面是否真实切换。
- 查询不到日志：检查日志级别映射和时间范围过滤。
- 性能下降：减少上下文长度，清理不必要历史对话。

## 8. 安全建议
- API 密钥仅保存在本地配置中。
- 启用高风险工具前确认权限范围。
- 导出日志可能包含敏感信息，需谨慎存储和分享。
