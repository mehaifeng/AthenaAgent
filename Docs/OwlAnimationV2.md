## 实际变化

- 按轮廓连通区域隔离角色，再导出独立帧；不从等分网格把邻帧边缘一起裁入。
- 以旧版四张待机猫头鹰为配色参考，将全部动作统一为冷石墨灰、银灰面盘与深色飞羽；
  琥珀色眼睛保留为暖色焦点，动作轮廓、透明度和锚点不变。
- 导入器从配色母版生成平滑 RGB 映射并自动应用到 124 帧，重新切帧不会退回暖棕色源稿。
- 固定显示盒，手工记录关键动作锚点；飞翼大小不再改变控件 Width / Height。
- 使用单调时间选帧；每帧有独立时长，单次动作保持末帧，不重复取模。
- 位置和帧共用时间轴。小镇在挂载期间用共享 16ms 计时器采样，帧未变化时不重复通知图片绑定。
- 移动时长按距离计算，跨区播放起飞 → 振翅 / 滑翔 → 落地，重定向从当前采样位置开始。
- 工具执行状态与动画展示状态分离：工具结果立即返回，不等待动画；快速工具完成后先保留
  “目的地落地 → 一次完整区域动作”，再归巢并播放成功动作。连续快速请求只保留最新区域，
  同一区域动作合并，避免为了展示动画形成执行等待或无限播放队列。
- Runner 在每轮模型调用前发出的推理区请求属于可延后展示：如果前一个工具仍在飞行、落地或
  播放区域动作，必须等该动作完成后才返回推理区；新的实际工具目标仍可覆盖尚未开始的推理返程。
- 5–9 秒错峰游走；飞行、落地和终态不接受随机游走。避让没有找到可用位置时保留原地。
- 呼吸来自素材中的细微姿态变化，移除了原来的全身 8% 缩放。标签保持独立，新增随高度变化的地面影子。
- 谢幕等待归巢飞行结束；入口飞行与小镇共用缓存，不再分别加载四帧素材。
