# 游戏模式 M2 手动验收清单

> 2026-10-11。M2 给城邦加了积累系统（藏品、橄榄林、居民、委托板、神谕、传令官）、群岛海图和程序化美术库（建筑套件、器物、植物、
> 会动的人物、2D 半身像）。设计见 `Docs/GameMode_Design_CN.md`，进度、决定、美术审查记录与证据见 `Docs/GameMode_Progress_CN.md`，
> 换外部模型见 `Docs/GameMode_AssetManifest_CN.md`。自动化测试已覆盖的部分（存档、推导、意图校验、审批……）这里不再重复；
> 这份清单只列需要人在真实窗口里看一眼、点一下的事。每一项后面的「预期」是通过的样子。M1 的清单（`Docs/GameMode_M1_Acceptance_CN.md`）仍然有效。
>
> **2026-10-13 起雅典娜不镜像回合（直播拿掉了，见 `Docs/GameMode_Progress_CN.md` 顶上一节）。** 1.2 的「等她交付」改为「等这一回合结束，
> 成果直接出现在你脚下」；8.2 整项废止（她不再做事、交付、等审批；走路早在 M3 改成了步行）。

## 0. 准备

- 构建并启动应用（开发机）：`dotnet build Athena.UI.sln -p:UseAppHost=false`，然后照常运行。
- 一个**测试用的工作区**（不要用重要的文件夹），里面放几个子文件夹，各放几份文档、图片、表格；在里面开两三个会话，
  各做一两件事（让雅典娜读文件、写一份文档、查一次网页），这样城里会有居民、林子里会有树。
- 审批模式用缺省的「平衡」。右侧日志面板开着。

## 1. 港前的公共区与藏品（设计稿 7.2）

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 进入游戏模式，把镜头往港口那边拖（右键拖动），或者用 WASD 走过去 | 港口两侧伸进海里三块石台：**彩绘柱廊**（长廊、后墙挂着一排画板）、**书库**（四根爱奥尼亚柱、上面一层小方窗、四坡顶）、**金库**（灰石方屋、包铜的大门）；每块台子上两排各 6 个底座；再往西是**橄榄林**的台地 |
| 1.2 | 让雅典娜写一份文档，等她交付，点那件红色的卷轴 → 「收下」 | 颜色褪掉，它出现在**书库**第一个空底座上（彩绘板去彩绘柱廊、账册去金库） |
| 1.3 | 点书库底座上的那件 → 「换个地方」 | 镜头转向场馆，空着的底座上出现一胀一缩的白环；顶上一条提示「点一个空底座……」+「放进书库」+「取消」 |
| 1.4 | 点**金库**的一个空底座 | 它搬到金库那个位次上（摆在哪由你决定，不限于它那一类的场馆） |
| 1.5 | 点它 → 「撤下」 | 它从底座上消失，回到"收着"；点书库的建筑，面板里「收着的藏品」能看到它，点「摆进这里」又摆回去 |
| 1.6 | 在访达里把那份文档**彻底删掉**，切到别的城再回来（或重启） | 传令官报「…找不到了」；底座上**只剩空底座**，上面一块虚线框的名牌写着它的名字；记录还在 |
| 1.7 | 点那个空底座 → 「移除」 | 只有这时这条记录才被删掉（不自动删除）；没遗失的藏品卡片上没有「移除」 |
| 1.8 | 再把一份**被挪了位置**的文档（移到别的文件夹）对应的藏品找回来 | 回来时传令官报「…换了地方，已经找回」；它仍在原来的底座上 |

## 2. 橄榄林（7.2）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 去橄榄林的台地 | 这座城里**每份完成过的委托一棵树**，按开始的先后排；回合多的树更老、更粗（树苗 / 小树 / 成树 / 老树） |

| 2.4 | 在对话模式里删掉一个会话，回到游戏 | 它的树没了（林子不另存，从会话推导） |

## 3. 居民（7.2）

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 看城里的人 | 用过的每项能力一位居民，站在那项能力的建筑旁：测绘员（宽檐帽、长测杆）、抄写员（石板与笔，在书库前）、账房（算板，在金库前）、铁匠（尖毡帽、锤子，在锻炉）、水手（港口，收缆）、图书管理员（长胡子，在圆形图书馆）、传令官（权杖，在广场的讲台）、画师（在彩绘柱廊前）……；没用过的能力没有人 |
| 3.2 | 看还没说过话的居民 | 头上名牌后面有个省略号「…」（他有话要说；不带红色——那不是"轮到你了"） |
| 3.3 | 点一位居民 | 底部弹出对话面板：左边是他的**白底陶瓶风格的线描半身像**，右边讲这项能力**还能做什么** |
| 3.4 | ~~点「请雅典娜试试」~~（2026-10-13 撤下：职业居民不再和工具挂钩，卡片上是「聊几句」，见 M4 验收） | — |
| 3.5 | 再看那位居民 | 名牌上的「…」没了（已结识，存进存档） |
| 3.6 | 等一会儿 | 居民停一会儿、干一会儿自己的活（举锤、写字、收缆……），隔一阵走出几步再走回来 |

## 4. 委托板（7.3）

| # | 操作 | 预期 |
|---|---|---|
| 4.1 | 点广场上的石碑（委托板） | 雅典娜的半身像 +「这里有几件可以交给我的事」+ 三条具体的建议（例如「「下载」里混着 300 件东西，要不要分分类？」），只看文件夹的名字、数量、时间，不读文件内容 |
| 4.2 | 点一条后面的「交给雅典娜」 | 新开一份委托，城里的对话栏带着这件事的请求展开，不发送 |
| 4.3 | 第一次进入一座新城 | 奠基揭幕之后，雅典娜头上说出委托板的第一条建议 |

## 5. 神谕（7.3：仪式就是那次批准）

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | 点神庙 | 面板说明每日神谕是什么，按钮「请雅典娜设立」 |
| 5.2 | 点它 | 新开一份委托，城里的对话栏带着一段请求展开：用 `create_task` 建一个每天早上 8 点的任务，任务名「每日神谕」，带着这个工作区的 Id；**不会自动发送** |
| 5.3 | 按 Enter 托付 | 雅典娜调用 `create_task` 时，**原生审批窗口弹出**（自动审批模式下也弹给人——定时任务只能由人批准）；网页里没有任何"批准"按钮 |
| 5.4 | 在审批窗口里同意 | 任务建好；回到城里，神庙前立起一只三足鼎和两丛月桂，女祭司出现在神庙前；再点神庙：「每日神谕已设立 · 0 8 * * * · 下一卷：…」 |
| 5.5 | 第二天早上（或者在定时任务页「立即运行」一次）之后回到这座城 | 传令官报「每日神谕送来了一卷，放在广场上等你」，广场南边多一件红色的回答；点这一行会选中那次运行开的会话 |
| 5.6 | 在审批窗口里拒绝（另试一次） | 不建任务，神庙仍是"请雅典娜设立" |

## 8. 美术（程序化美术库）

| # | 操作 | 预期 |
|---|---|---|
| 8.1 | 在一个代码仓库里进游戏 | 一大片作坊不再一模一样：有的是陶工（窑和烟囱）、有的是织工（屋侧立着的织机）、木工（木料、锯木架）、石匠（方石、人字吊架）；木棚是浅色的苇顶，不是黑色的一块板 |
| 8.2 | 看雅典娜走路、做事、交付 | 走路是**滑行**（衣摆向后拖、身体前倾，不露脚）；读文件时捧着卷轴低头读，写文件时左手托石板右手写，锻炉前举锤落锤，查网页时往回收一根缆；交付时俯身、双手递出红卷轴、放在你脚下再起身；等审批时双手捧着石板，石板上一道红绳、一枚红封印 |
| 8.2b | 看居民 | 走着、站着的时候手里也拿着自己那一行的家什：测绘员、传令官的长杖是竖着的，抄写员抱着石板、账房抱着算板、画师托着调色板；只有雅典娜手里会出现红色 |
| 8.3 | 用 WASD / 方向键走动（点地面不再走路） | 你迈步走（兜帽斗篷，没有光） |
| 8.4 | 看橄榄树 | 不再像花椰菜：扭曲分叉的老枝、偏平的一簇簇叶团、中间有空隙 |
| 8.5 | 在城里截一张图，和 M1 的截图放在一起 | 光照是同一套：正午的高调光、软阴影、黑白，只有"轮到你了"的东西是赤陶红 |

## 10. 实测之后的操作（2026-10-11：说话、视角、走路）

M2 之后的实测定下了三处改动：游戏盖住整个中间区域、说话在城里的对话栏；视角加了自由视角并且缺省选中它；WASD / 方向键走路、鼠标点物件互动。
页面逻辑由 Node 单测、Playwright 冒烟（Chromium 与 WebKit）和运动自检覆盖；这里只列要在真实窗口里试的事——尤其是原生 WebView 的键盘焦点，
那是浏览器里的测试看不到的。

| # | 操作 | 预期 |
|---|---|---|
| 10.1 | 进入游戏模式 | 城邦占满标题栏以下的整块，原来的输入框不见了；底部正中一条对话栏（左边一枚雅典娜的小像、「想请雅典娜做什么？」）；左上角「视角：自由 / 跟着你 / 跟着雅典娜」，**自由**是选中的；对话栏上方一行操作提示 |
| 10.2 | 不点画面，直接按 W | 如果人没动、提示写着「点一下画面，就能用键盘走动」：这是原生 WebView 还没拿到键盘焦点，点一下画面空地再按 W 就能走（请记下你的系统上是哪一种） |
| 10.3 | 按住 W / A / S / D（或方向键），再按住 Shift | 人朝画面上方 / 左 / 下 / 右走，Shift 跑起来；撞上房子沿着墙滑，走不进房子、走不下海；走过第一步之后提示消失 |
| 10.4 | 左键按住拖动；右键拖动；滚轮 | 左键拖动绕着转（只拖一点点仍然是点击）；往下拖看得更俯，有上限；右键拖动平移；滚轮缩放 |
| 10.5 | 自由视角下一直往一个方向走 | 镜头不跟着你转，但你快走出画面时它会跟上，你一直在画面里 |
| 10.6 | 点雅典娜 | 对话栏展开：她的半身像、「她在听」、能写几行的输入框；指针停在她身上时脚下有一块「和雅典娜说话」 |
| 10.7 | 在对话栏里打几个带 w、a、s、d 的字，用中文输入法选字时按 Enter | 人不动（这些是字不是脚步）；选字的 Enter 只是选字，不会托付 |
| 10.8 | 按 Enter 托付一件事 | 对话栏收起，左侧这个会话里多了你的这句话（切回对话模式能看到），雅典娜说一句「好，我来办」之类的话，出发去干活；对话栏占位字变成「她在办你交代的事」，托付键换成「请她停下」 |
| 10.9 | 点「请她停下」 | 这一回合停下，和对话模式里按停止一样 |
| 10.10 | 在对话栏里写半句话，切回对话模式 | 输入框里是那半句话；再切回游戏，对话栏里也还是它 |
| 10.11 | 她走到画面外去干活 | 屏幕边缘一枚白色的圆标「雅典娜在这边」指着她；点它，视角切到「跟着雅典娜」 |
| 10.12 | 按 V 几次；按 M；按 Esc | V 在三种视角之间轮换（左上角跟着变）；M 打开 / 关上海图；Esc 收起最上面的那一层（阅读器、海图、卡片或面板） |
| 10.13 | 点一件红色的卷轴、一位居民、一棵橄榄树、委托板、神庙、场馆 | 和以前一样打开卡片或面板；指针停在它们上面时光标变成手指；点空地什么也不发生 |
| 10.14 | 走一段路之后切到别的城再切回来（或重启） | 你还站在离开时的地方 |
